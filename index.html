面向 Shopify Theme Kit 的 SCSS 工具链

易上手、稳定、可扩展：为日常页面开发提供更顺滑的“写样式 → 编译 → 上传”体验。

Quick Start GitHub
01

开箱即用

一条初始化命令接入工具链、默认配置、脚本和示例结构。

02

一键启动

联动响应式生成、Sass 编译、安全同步和 Theme Kit watch。

03

per-entry 覆盖

为每个入口生成独立移动端覆盖文件，降低页面之间互相污染的风险。

04

安全写入策略

默认通过 marker 与 .new 兜底保护旧 CSS，减少误覆盖历史文件。

05

SCSS 组织体验

入口、partial、变量与函数可以按组件和页面拆分维护。

06

多设计稿适配

支持 750、590、375 等移动端设计稿对应的 clamp 策略。
