易上手、稳定、可扩展：为日常页面开发提供更顺滑的“写样式 → 编译 → 上传”体验。

相对保守的修改策略，较低的误删、误修改风险。

流畅、简洁、灵活的开发体验。

良好的适配性

适配三种不同的移动端设计稿。

你写的 SCSS

.hero {
  padding: r.vw(60px, 32px);
  background: r.re(#1a1a2e, #f5f5f5);
}

.hero__title {
  font-size: r.resp(56px, 28px, h1, h2);
}

.hero__desc {
  margin-top: r.vw(24px, 12px);
  color: r.re(rgba(255,255,255,0.8), #333);
}

.hero__grid {
  display: r.re(grid, flex);
  grid-template-columns: r.re(grid-cols-3, grid-cols-1);
  gap: r.vw(32px, 16px);
}

生成的覆盖（示意）

/* PC output */
.hero {
  padding: min(calc(60 * var(--px-to-vw)), 60px);
  background: #1a1a2e;
}
.hero__title {
  font-size: clamp(39.2px, calc(56 * var(--px-to-vw)), 56px);
}
.hero__desc {
  margin-top: min(calc(24 * var(--px-to-vw)), 24px);
  color: rgba(255,255,255,0.8);
}
.hero__grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: min(calc(32 * var(--px-to-vw)), 32px);
}

/* Mobile overrides (autofill generated) */
@media (max-width: 850px) {
  .hero {
    padding: calc(32 * var(--px-to-vw-mb));
    background: #f5f5f5;
  }
  .hero__title {
    font-size: clamp(16.8px, calc(28 * var(--px-to-vw-mb)), 28px);
  }
  .hero__desc {
    margin-top: calc(12 * var(--px-to-vw-mb));
    color: #333;
  }
  .hero__grid {
    display: flex;
    grid-template-columns: repeat(1, 1fr);
    gap: calc(16 * var(--px-to-vw-mb));
  }
}
